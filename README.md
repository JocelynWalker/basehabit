# BaseHabit

BaseHabit is a Base Mini App for repeated habit creation, repeated check-ins, streak tracking, growth points, and referral attribution.

The app uses Next.js App Router, TypeScript, Tailwind CSS, Wagmi, and Viem. It does not use RainbowKit, WalletConnect UI, or `getDefaultConfig`.

Production app:

https://basehabit.vercel.app
